Bug reports

Filed against FearlessLang/StandardLibrary and Commons while working on the codebase. Last updated 2026-09-08.

  • MetaParser.parseBack index arithmeticopen Commons: parseBack read the caller's absolute limit field where it needed a token-window-relative value, corrupting the parser's cursor. A fix and regression test were proposed (Commons#24, Frontend#36) but closed without merging. Published 2026-09-07.
  • Nat range .sizefixed StandardLibrary: an inclusive Nat range's .size computed startInclusive - endInclusive instead of endInclusive - startInclusive + 1, throwing for any multi-element range. Published 2026-09-03, fixed upstream shortly after.
  • Empty List .subListfixed StandardLibrary: an empty List's .subList(start,end) guarded with && instead of ||, so a call with start==0 silently returned {} instead of throwing when end exceeded size. Published 2026-09-04, fixed upstream shortly after.
