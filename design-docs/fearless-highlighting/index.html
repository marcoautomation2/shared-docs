Fearless syntax highlighting design

A design proposal for editor syntax highlighting in Fearless, plus a tested TextMate grammar proof of concept. Fearless has almost no keywords and literals are type names, so "which category is this identifier" is not always something a lexer alone can answer. Published 2026-09-13 as an open discussion, not a merged feature.

  • proposal.md The full write-up, rendered below.
  • fearless.tmLanguage.json The TextMate grammar POC. Tested with the real vscode-textmate/vscode-oniguruma engine against all 88 .fear files in StandardLibrary: zero unclassified characters.
