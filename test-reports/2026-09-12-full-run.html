TestAgentTools — first attempt failed on environment, not code investigated

The first run of TestAgentTools.java failed immediately with a desktop-portal error, not a test assertion:

gi.repository.GLib.GError: g-dbus-error-quark: GDBus.Error:org.freedesktop.DBus.Error.Failed: Session creation inhibited (0)

Failures (1):
  JUnit Jupiter:DesktopDragTest:aFileDraggedBetweenTwoFolderWindowsMovesThere()
    => java.lang.NullPointerException: Cannot invoke "String.equals(Object)" because "<local2>" is null
       agentTools.Mutter.send(Mutter.java:45)
       agentTools.Mutter.shot(Mutter.java:52)
       agentTools.Pilot.shot(Pilot.java:38)
       agentTools.DesktopDragTest.aFileDraggedBetweenTwoFolderWindowsMovesThere(DesktopDragTest.java:28)

Cause: GNOME's screensaver/idle-blank state (org.gnome.ScreenSaver GetActive returned true, distinct from a locked session) makes org.gnome.Mutter.RemoteDesktop CreateSession refuse to open, which the test wraps in a NullPointerException when it tries to use the missing session. Fix applied: deactivate the screensaver over D-Bus (org.gnome.ScreenSaver.SetActive false) and re-run; no code, test, or repo content was changed. The re-run passed cleanly (19.5s, 1/1 tests, 4/4 containers).
