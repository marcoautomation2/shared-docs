Cheap coding-model APIs for harness testing

Survey of per-token pricing and free/no-card options across model providers, for prototyping a home-grown agentic coding harness against raw APIs (not Claude Code itself). Researched overnight, 2026-09-13.

Context: Anthropic's Claude Code Pro/Max subscription credentials only work inside Claude Code / claude.ai (enforced server-side since April 2026). A custom harness needs either a metered Anthropic API key (requires a card) or one of the alternatives below.

Recommendation

1. OpenRouter — free-tier hosted models no card

One signup, one OpenAI-compatible API key and endpoint, 20+ rotating :free models (Qwen, DeepSeek, Llama, GLM, and others) behind it. 50 requests/day and 20 requests/minute on a $0 balance — enough to exercise a harness's tool-call loop, retries, and streaming against a real hosted model without spending anything. Because it's a single OpenAI-compatible shape, it is also the fastest way to check whether a harness's abstractions actually generalize across model families. Optional manual step: buying $10 of credit (Marco's card) raises the daily cap to 1,000 — not required to start.

2. Local Ollama, qwen2.5-coder:3b free forever, already installed

Already running on this machine (re-pulled tonight after a prior reset wiped the model cache — see log). Zero cost, zero account, no rate limit, no network dependency. CPU-only inference is slow (seconds per reply, no GPU on this box) and a 3B model's code quality is well below any hosted option below, so treat it as a target for exercising the harness's plumbing (request/response shape, tool-call loop, error handling), not for judging real code quality.

Runner-up: GitHub Models. The marcoautomation2 GitHub token already in use on this machine works against it today with zero new signup, and its GPT-4o/Claude/Llama/Phi lineup is explicitly scoped by GitHub's own terms to prototyping and experimentation — a close match for "testing a harness." Listed second only because its per-model rate limits are tighter and less clearly documented than OpenRouter's.

What Marco would need to do by hand

  • Nothing, to start testing today: OpenRouter signup and the local Ollama model need no card and no manual verification.
  • To raise OpenRouter's daily cap from 50 to 1,000 requests: add $10 of credit at openrouter.ai (his card).
  • To use any of the paid-only options in the pricing table above (Anthropic, OpenAI, Groq beyond the free catalog, Gemini beyond the free tier, DeepSeek, Qwen beyond its free quota): create an account and add a payment method at that provider's own console (console.anthropic.com, platform.openai.com, ai.google.dev / Google Cloud console, platform.deepseek.com, console.groq.com, dashscope console). None of this was done automatically — entering payment details is explicitly outside what an overnight agent does on its own.

Method & confidence

Pricing and free-tier terms for Anthropic, OpenAI, Google Gemini, DeepSeek, and OpenRouter were confirmed directly against each provider's own documentation. Groq, Cerebras, Alibaba Qwen, Mistral, and GitHub Models are cross-checked across multiple independent secondary sources but not independently re-verified against a primary console/docs page in this pass — flagged above wherever that applies. The web currently carries many near-identical SEO aggregator pages restating the same numbers per provider; these were treated collectively as one weak source even when several agreed, and a primary source was preferred whenever it could be fetched.
