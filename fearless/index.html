Running it

  1. First run of any project compiles it and takes a few seconds; it leaves a .fearless_out cache next to the sources and later runs are quick.
  2. Unzip anywhere â€” the app is relocatable and writes nothing outside its own folder plus the usual per-user data dir.
  3. The portable build wants a project folder as its argument; started with no argument it sits on the welcome window. Unzip the examples next to it and point at one, e.g. fearlessBin0_001.exe fearless-examples_hello_world.
  4. Windows SmartScreen will warn on first run: the executables are unsigned.
